# Управление реализации газа — дашборд «Мировые рынки газа» — демо-дашборд

Интерактивный дашборд для руководства: факт 2021–2025 (годовые ряды, добыча — квартальная) и прогноз 2026–2035 по ценам и объёмам (экспортные потоки, СПГ, внутреннее потребление, добыча, Европа, Китай, Средняя Азия). Прогноз есть на всех графиках, включая квартальную добычу (синтетический).
Без KPI-плиток, светофоров, план/факт, спотовых бенчмарков (TTF/JKM/Henry Hub), рисков и санкций, без live-обновления
(данные обновляются заменой CSV — не чаще раза в квартал).

> **Все данные в папке `data/` — синтетические демо-данные.** Они не являются официальными. Контрагенты в контрактах обезличены.

## Запуск

Нужен любой статический веб-сервер (браузер не даёт `fetch` для CSV при открытии `index.html` двойным кликом).

**Windows, без установки чего-либо** (PowerShell):
```bash
powershell -ExecutionPolicy Bypass -File serve.ps1 -Port 8765
```
Откройте http://localhost:8765/

**Если есть Python / Node:**
```bash
python -m http.server 8765
```
```bash
npx serve .
```

Библиотеки (ECharts 5.5.1, SheetJS 0.18.5) лежат в `vendor/`, поэтому сайт работает **без интернета**.

## Архитектура и обоснование

**Статический клиентский сайт: HTML + CSS + чистый JavaScript, ECharts (графики и карта), SheetJS (Excel). Без сборки и бэкенда.**

- Данные обновляются раз в квартал и лежат в CSV/Excel → серверная логика не нужна; замена файла = обновление дашборда.
- Нет Node/сборки/зависимостей в рантайме: сайт можно положить на любой внутренний веб-сервер, SharePoint или общий диск с веб-доступом.
- ECharts даёт choropleth-карту по GeoJSON, наложение прогноза (штриховка, markArea), единый стиль тултипов.
- Если позже понадобятся БД, авторизация и API — тонкий слой подмены `DataLoader` (`js/data.js`) заменяется на вызовы API, остальной код не меняется.

## Как заменить CSV

1. Сохраните новый файл в `data/` в кодировке UTF-8, разделитель — запятая, **те же названия колонок** (набор колонок — по ТЗ; колонка `source` необязательна, но попадает в тултипы).
2. Если имя файла другое — поправьте `CONFIG.files` в `js/config.js`.
3. Обновите страницу (Ctrl+F5). Диапазон лет определяется по данным; код менять не нужно.

Нюансы: `is_forecast` = `0/1`; единицы по ТЗ (млрд куб. м, млн т, USD/тыс. куб. м, USD/т); названия регионов в `domestic_consumption.csv` должны совпадать со свойством названия в GeoJSON (несовпадения выводятся предупреждением в консоль браузера).

## Как подключить GeoJSON регионов РФ

Карта построена на реальных границах 85 субъектов (Natural Earth admin-1, общественное достояние, упрощённые 50m, проекция Альберса) — `data/geo/russia_regions.geojson`, собирается скриптом `tools/build_geojson.ps1`. Границы упрощены и не заменяют официальные; Крым и Севастополь включены как в источнике. Чтобы подключить свой GeoJSON:

1. Возьмите GeoJSON субъектов РФ (FeatureCollection, полигоны/мультиполигоны в WGS84; желательно упрощённый, до 1–3 МБ). Для регионов, пересекающих 180° (Чукотка), используйте вариант со сдвигом долгот.
2. Положите файл как `data/geo/russia_regions.geojson` (или укажите путь в `CONFIG.geo.url`).
3. В `CONFIG.geo` задайте `nameProperty` — поле `properties` с названием региона (например, `name` или `NAME_1`). Названия должны совпадать с колонкой `region` в CSV (при необходимости приведите CSV к названиям из GeoJSON).
4. Если нужны подписи — укажите `shortProperty`; если поля нет, подписи не показываются. Для настоящей карты поставьте `showLabels: false`.

## Как добавить реальные источники

- Замените файлы в `data/` выгрузками из внутренних систем/открытых источников; в колонке `source` указывайте источник — он выводится в тултипах.
- Для автоматической подгрузки раз в квартал настройте задание, которое перезаписывает CSV (планировщик, ETL-скрипт). Страница читает файлы при открытии.
- Для API/БД замените `loadCSV` в `js/data.js` на запрос, возвращающий массив объектов с теми же полями.

## Где менять цвета

- **Цвета карты (choropleth):** `CONFIG.mapColors` (шкала от меньшего к большему), `mapBorder`, `mapSelectedBorder`, `mapNoData` — `js/config.js`.
- Цвета рядов (компании, страны, сегменты цен): `CONFIG.colors` там же. Общие цвета интерфейса — переменные `:root` в `css/style.css`.

## Что есть в интерфейсе

- Главный экран — 9 блоков: карта, диаграмма Санкея экспортных потоков (трубопроводный — млрд куб. м и СПГ — млн т, отдельными диаграммами), Восток vs Запад, потребление РФ, добыча, цены, Европа, Китай, Средняя Азия. Детали — во вкладках «Регионы РФ», «Добыча», «Европа», «Китай», «Средняя Азия», «СПГ-контракты», «Цены».
- Фильтры: год, направление, тип газа, регион РФ (карта), компания (добыча), проект и регион покупателя (контракты). Фильтры не создают KPI-плиток.
- «Восток vs Запад»: год, когда Китай обогнал Европу, определяется автоматически по данным и подписывается на графике.
- Прогноз цен (2026–2035) выделен штриховой линией, заливкой и подписью «прогноз»; в таблице — закрашенные столбцы.
- Доля России в трубопроводном импорте Китая рассчитывается как экспорт «на восток» (`export_flows`) / импорт трубопроводного газа Китаем (`china_market`).
- «Выгрузить в Excel» — листы «Потребление по регионам», «Добыча по компаниям (квартал)», «Контракты», «Цены».
- Пересоздать демо-данные: `powershell -ExecutionPolicy Bypass -File tools\generate_demo_data.ps1`.

## Известные ограничения демо

- Границы карты упрощены (Natural Earth 50m); для презентаций высокого разрешения подключите свой GeoJSON.
- Блок «СПГ-контракты» показывает только СПГ-строки `contracts.csv`; трубопроводные контракты попадают в Excel-лист «Контракты».
- Прогноз цен — иллюстративные значения, не расчёт модели.
